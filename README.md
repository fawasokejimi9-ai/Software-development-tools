# Software-development-tools
SOFTWARE DEVELOPMENT TOOLS

Introduction

Software development involves the use of different tools and technologies to plan, design, write, test, manage and maintain software applications.

This assignment introduces the major tools used in software development, including requirements management tools, design and modelling tools, Integrated Development Environments (IDEs), and source code management systems.

1. Requirements Management Tools

Requirements management tools help software developers collect, organise, document and track the requirements of a software project.

IBM Rational DOORS is a requirements management tool used to manage project requirements, track changes and ensure that the final software meets the specified needs.

Other comparable tools include:

- Jama Connect
- Siemens Polarion ALM
- Azure DevOps

2. Design and Modelling Tools

Design and modelling tools help developers visualise the structure, behaviour and processes of a software system before implementation.

Sparx Enterprise Architect is a modelling tool used to create diagrams and represent software systems using Unified Modelling Language (UML).

Other alternatives include:

- Visual Paradigm
- StarUML
- Lucidchart

3. Integrated Development Environments (IDEs)

An Integrated Development Environment (IDE) is a software application that provides programmers with tools to write, edit, run, test and debug their code in one environment.

Examples include:

- Eclipse: Commonly used for Java development.
- IntelliJ IDEA: Mainly used for Java and Kotlin development.
- NetBeans: An IDE commonly used for Java programming.
- Microsoft Visual Studio: Supports languages such as C#, VB.NET and C++.
- Xcode: Used for developing applications for Apple platforms.

4. Source Code Management

Source code management is the process of tracking and controlling changes made to a software project's source code.

It helps developers maintain different versions of their projects, collaborate with other programmers and recover previous versions when necessary.

Important terms include:

Repository: A storage location containing project files and their version history.

Commit: A recorded snapshot of changes made to a project.

Branch: A separate line of development that allows developers to work on new features without affecting the main project.

Merge: The process of combining changes from different branches.

Pull Request: A request to review and approve changes before merging them into another branch.

Version Control: A system that records changes to files over time and allows developers to manage different versions of their work.

5. Git and GitHub

Git is a distributed version control system used to track changes in source code and support collaboration among developers.

GitHub is an online platform that hosts Git repositories and provides collaboration features.

Git allows developers to track changes locally, while GitHub makes it possible to store and share projects online.

Some common Git commands include:

- "git init" – Initialises a Git repository.
- "git add ." – Stages changes for a commit.
- "git commit -m "message"" – Records changes.
- "git branch" – Displays available branches.
- "git merge" – Combines branches.
- "git push" – Uploads local commits to a remote repository.
- "git pull" – Retrieves and integrates changes from a remote repository.

6. Issue Tracking, Documentation and Continuous Integration

Issue Tracking: This involves identifying, reporting and monitoring bugs, problems and tasks within a software project.

Documentation: Documentation provides written information about a software project, including its purpose, installation instructions, usage and maintenance.

Continuous Integration (CI): Continuous Integration is a software development practice where developers regularly integrate their code changes into a shared repository, with automated processes used to build and test the application.

7. Pre-Class Activities

The following activities are part of the preparation for this topic:

1. Create or verify access to a GitHub account.
2. Install Git and an appropriate IDE, or identify available browser-based alternatives.
3. Watch the assigned introductory video.
4. Review the basic concepts of repository, commit, branch, merge and version control.

Conclusion

Development environments, modelling tools and source control systems play important roles in modern software development.

They help developers plan projects, design software systems, write and test code, track changes and collaborate effectively.

Understanding these tools provides a foundation for developing and managing software projects successfully.
